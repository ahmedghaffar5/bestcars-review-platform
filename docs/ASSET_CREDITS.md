# Asset credits

The redesign intentionally uses an original image-free editorial treatment.
The hero is composed from CSS gradients and geometric facet lines authored in
`server/frontend/styles/obsidian.input.css`; it does not imply that a photograph depicts
a listed dealership or its inventory.

An initial bounded search checked Wikimedia Commons as a possible source for a
cohesive, permissively licensed automotive collection, but the available
network could not reliably retrieve the authoritative file pages or originals.
No image has therefore been presented as licensed, downloaded, or suitable for
public repository redistribution. The inherited, provenance-unclear
photographs are no longer referenced by the public pages.

If verified photography is added later, record each local WebP filename,
creator, original source page, license URL, acquisition date, modifications,
responsive variants, and required attribution in this document before use.
