# Acknowledgements and project origin

Best Cars is adapted from the IBM Skills Network
`xrwvm-fullstack_developer_capstone` starter:
https://github.com/ibm-developer-skills-network/xrwvm-fullstack_developer_capstone

The starter supplied application structure, sample datasets, frontend components,
and assets. Ahmed Ghaffar completed and integrated the dealership/review workflows
and worked through containerization, cloud configuration, and deployment testing.
The project was developed with AI coding assistance and iteratively checked through
source review, tests, and live lab execution. It is not presented as a framework or
model invented entirely from scratch.

The original Apache-2.0 LICENSE and upstream history are preserved. Copyright and
license notices in retained source/assets must not be stripped. Copied course
instructions and grading paperwork are omitted from the portfolio working tree;
removing them does not remove IBM attribution.

Screenshots in `docs/screenshots/` are from the owner's working demonstration.
Browser chrome was cropped; review content, account labels, and app state were not
altered. These images document a previous demonstration, not current live uptime.
