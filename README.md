# fullstack_developer_capstone

Best Cars is a Django, React, Express/MongoDB, and Flask/NLTK dealership review portal based on the IBM Full Stack Application Development Capstone starter project.

Local services:

- Django and React: `http://localhost:8000`
- Express and MongoDB: `http://localhost:3030`
- Flask sentiment analyzer: `http://localhost:5000`

See [docs/LOCAL_SETUP.md](docs/LOCAL_SETUP.md) for Windows PowerShell and Linux commands. GitHub fork/push, IBM Code Engine, IBM Container Registry, Kubernetes, and hosted Option 1 evidence remain pending until external access is intentionally enabled.
